# IP and Provenance Register

Repository: `eliteacsllc/ELITE-ESTIMATING-`.

Git history is the primary authorship record. Third-party repair/estimating data, OEM procedures, labor/parts databases, images, provider APIs, licensed reference material and generated content are not treated as owned merely because an adapter or derived implementation exists.

Release requires exact-release dependency/license review; documented rights for every bundled dataset, model, image and reference source; provider contracts/credentials for proprietary feeds; and provenance for generated or imported material. Original implementation must not reproduce proprietary CCC, Mitchell, Audatex or other protected code/content/method expression without authorization. Unknown rights block release.

Contracts and confidential provider evidence remain outside Git and are referenced from the controlled release record.
