# UX Standard

This product follows the Elite portfolio-wide Zero-Training / Fast-Value UX Standard.

Release requirement: a first-time user must understand the product, identify the next action, complete the primary workflow, recover from errors, and reach meaningful value without training.

Required principles:
- outcome first, configuration second
- plain business language before technical terminology
- guided defaults and automatic context extraction where safe
- obvious next action on every critical screen
- preserve progress and provide plain-language recovery
- progressive disclosure for advanced controls
- every critical button and workflow must function before release

Critical UX confusion is a release blocker.
