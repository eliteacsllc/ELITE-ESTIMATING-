# Elite Estimating Tutorial Media

## Audience
Estimators, appraisers, repair facilities, reviewers, and integration developers.

## Required tutorials
- Product overview and estimating workflow.
- First estimate: vehicle/job setup, damage capture, operations, parts/labor, notes, totals.
- Evidence-backed repair procedure lookup and source/provenance review.
- Estimate QA: omissions, overlaps, labor/operation checks, supporting evidence, corrections.
- Supplements and revision history.
- Export/integration workflow.
- Developer/API guide where applicable.
- Troubleshooting data-provider, evidence, export, and calculation issues.

## Core demo storyline
Create a synthetic repair job -> capture damage -> build estimate -> attach evidence -> run QA -> correct findings -> create supplement -> export final deliverable.

## Safety
Use synthetic VIN/customer/claim data. Do not present unverified repair procedures, pricing, labor times, or provider-derived values as authoritative without source/provenance.

## Acceptance
All math shown in tutorials must reproduce correctly; evidence links must resolve; unsupported repair claims must be blocked or labeled; captions and on-screen estimate text must pass spelling/grammar verification.
