# Elite Frontier Fabric Adapter

This repository remains independently operable. The shared Elite Frontier Fabric is an optional capability multiplier, not a runtime prerequisite.

Ownership remains with this product: estimate-authoring, estimate-review, estimating-calculations.

Cross-portfolio intelligence uses `elite.frontier-handoff.v1` and `elite.frontier-receipt.v1`. Tenant and correlation identity must be preserved. The adapter cannot bypass this product's authorization, evidence, approval, or human-review controls.

When the shared fabric is unavailable, the product falls back to its native capability path.
